# Application Staples

For an identified job opportunity, “prereqs,” “pre-reqs,” “prerequisites,” “preqs,” “staples,” “application staples,” and “job application staples” request preparation of four items:

1. Application form or URL. Verify the exact employer, role, and application route.
2. Résumé. Select or tailor a sourced résumé and link the upload-ready file.
3. Cover letter. Prepare a role-specific letter and link it. Use the form to determine whether the employer requests it.
4. Local answers prepped. Stage sourced answers for the exact opportunity in the private workspace or handoff. Distinguish observed questions from anticipated ones and flag unknown, unapproved, or manual-only answers.

Return usable links and unresolved items, and record evidence in the user-owned tracker when available. Keep applicant files and values out of Git. A private handoff is prepared material. Claim saved local answers only after exact-opportunity readback.

The bound form governs required fields and attachments. Follow Resume Presentation and Application Form Intake in [Workflows](../WORKFLOWS.md). Preparation invokes no submission action.

For inbound recruiter contacts, use [Recruiter outreach](../WORKFLOWS.md#recruiter-outreach) to record the source and next action.
