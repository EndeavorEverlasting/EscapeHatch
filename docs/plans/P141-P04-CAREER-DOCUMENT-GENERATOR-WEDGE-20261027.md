## P141 — Cheapest falsifying investigation; P82 admission candidate
**Question:** Do typed reusable author edits materially improve later application packets without sacrificing claim fidelity, fit or time?
**Independent signals:** (1) private operator revision/approved writing source exists; (2) repository has a derivative/provenance artifact contract and active repeated application demand; (3) external comparison observes generic one-shot drafts.
**Baseline/comparator:** For the same two distinct synthetic jobs plus one locally consented real, non-sensitive sample if available, compare:
- **B0**: current generator/baseline role résumé + cover letter + short answer (or record NOT_AVAILABLE; do not pretend there is a generator);
- **B1**: same model/prompts/context plus explicit static author voice card;
- **B2**: proposed typed author edit deltas and shared claim/role lineage, with no new facts.
Control model, job snapshot, word budget, format, and source evidence. Randomize anonymous blinded review order. A later competitor-generated sample is optional only when legitimately accessible and permitted.
**Primary empirical uncertainty:** whether B2 adds genuine improvement over the cheaper B1 without introducing cost or factual regression.
**Measurements:** blind author preference, preserved approved voice propositions, grounded-claim rate, invented/unsupported-claim count (hard zero), role-specificity, reviewer correction minutes, sentence/word cap adherence, document consistency, PDF text-extraction/page-layout gates and source-revision completeness. Never substitute an unexplained ATS score for real parser tests.
**Predeclared decision:** PROMOTE only if B2 outperforms B1 on author-preferred outcome in both job archetypes, demonstrates a measurable reduction in review changes or time, contains zero unsupported material claims, preserves mandatory formatting, and produces valid reversible receipts. REJECT if B1 performs equally well with lower complexity, B2 creates any unresolved consequential unsupported claim, or author changes are not reliably recovered. WEAKEN for modest gain with high integration burden; INCONCLUSIVE for insufficient/biased source samples. Record counts rather than fabricate numeric results. **P82 admission is PROPOSED; do not execute until baseline is actually accessible and the experiment input is provenance-verified.**
**Route:** P82 for a bounded comparative prototype **after** exact source availability/readiness is verified; P95 instead if source authority or call-stack boundaries remain ambiguous. P07 only after the experimental decision. P141 stops here; no production generator implementation under this scout.
