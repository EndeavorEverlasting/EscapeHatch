## Built design system and invariants

- Original operator illustration is immutable, content-hashed and versioned. The first selectable choice is **Identity Hatch**; **Classic Board** preserves a minimal alternative. New sets require unique slug, real PNG bytes, alt text, provenance, recorded hash/dimensions, approved reward identity and the existing safe source-piece keys.
- The gallery is embedded **inside** the old `ProfilePieceBoard`. All old ten buttons, inspection/review actions, keyboard focus, source timestamps, missing/review/unmeasured states and saved local profile semantics remain authoritative. No secondary career data store.
- Puzzle choice is **page-local only** because an immutable owner-scoped preference-store contract has not been established for this feature. Never use an unbound global localStorage key to sync preferences across users/devices.
- The artwork has preprinted checkmarks; caption and independent live state overlays explicitly distinguish its decorative rendering from actual profile evidence. Future art must never be relied on as evidence of saved/approved fields.
- `projectPuzzleGallery` recomputes counts and unlocks from the existing snapshot. An unavailable/unmeasured/review-needed/missing piece must keep the decorative milestone locked. The reward is a local visual keepsake, not currency, purchasable points, credentials, employer readiness or a persisted record.
- Current artwork mentions Preferred Name and Add Headline, while the existing ten-key projection contains other fields. These are illustrative motifs **only**, not a false mapping. To make those exact art labels actionable, first extend the canonical evidence projection using real approved sources, migrate its tests, then version the gallery schema. Do NOT label a professional summary as a verified headline or count preferred name through an unrelated field.
- Accessibility: native select, readable noncolor status labels on existing board, static reduced-motion visuals, 320px containment, no automatic sound, no unrelated page state changes.
- No automatic ATS form fill/upload/submit, no attestations, no personal content in public Git.
