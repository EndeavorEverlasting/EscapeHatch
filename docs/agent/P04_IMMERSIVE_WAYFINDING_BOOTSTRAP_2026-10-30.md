## What code changes
1. **Website:** a visible `/journey` route in desktop and mobile navigation; six interactive sequential *and directly openable* puzzle panels, six direct website destinations, all canonical root scenes listed with user-visible links and outgoing transitions. A scene guide is not application-progress evidence. PR #147's private skills studio will feed a future reviewable content surface, rather than being silently simulated by this navigator.
2. **Extension:** `journey-guide.js` adds six explicit learning scenes and navigates to actual existing popup controls without invoking Fill or Submit. Security-critical switches are **not** silently set by the guide. The existing routine privacy notice preference remains separately owner-controlled.

Existing install manifest/Node dependency-cache and checksum verification are preserved. A Windows installed-user proof is still required.
4. **Tests:** unit guard covers all scenes, routes and operator-only boundaries; browser test covers desktop/mobile/keyboard/reduced motion; extension harness guards no invisible phone controls and no false capability unlock; Windows test exercises per-user mascot-ICO generation when PowerShell exists. Existing cross-ATS parent gates and no-Submit contracts remain authoritative.
